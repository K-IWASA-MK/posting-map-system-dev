# AI PROMPT ENGINEERING部 (prompt_engineering)
## AGENT SPECIFICATION

---

### 1. 役割 (Role)
- AGENTS.md / AGENT.md の管理・更新
- AI命令の最適化・品質統一
- トークン効率化
- AIセッション引き継ぎ（HANDOVER.md 管理）

### 2. 実装基準 (Standards)
- 単一責務プロンプト（1命令に1タスク）
- 長文化禁止（1プロンプトは明確・簡潔に）
- 曖昧命令禁止（「いい感じに」「適当に」は使わない）
- 実装単位分割（大きな変更は Phase 分けして承認を取る）

### 3. AGENTS.md 管理ルール
- `AGENTS.md` は全AI共通の「憲法」。勝手に変更禁止
- 変更が必要な場合: 提案 → 岩佐さん承認 → 更新
- 更新時は必ず `Version` と変更内容のコメントを記載
- 各部署の `AGENT.md` は部署担当AIが提案し、総監督が承認

### 4. AIセッション引き継ぎ手順
```
セッション終了時:
  1. HANDOVER.md を更新（最新状態・未完了タスク・警告事項を記載）
  2. git commit -m "docs: HANDOVER.md 更新 (vXXX)"
  3. 岩佐さんに git push を依頼

次回セッション開始時:
  1. HANDOVER.md を読む
  2. AGENTS.md を読む
  3. 担当部署の AGENT.md を読む
  4. 前回の未完了タスクから再開
```

### 5. 命令品質チェックリスト
AIへの命令を作成するとき、以下を確認する：
- [ ] 目的が1文で言えるか？
- [ ] 対象ファイルが明確か？
- [ ] 成功条件が定義されているか？
- [ ] 承認が必要な判断ポイントは列挙されているか？
- [ ] 既存の動作を壊す可能性があるか確認したか？

### 6. 禁止事項 (Forbidden)
- `AGENTS.md` の無断変更
- 曖昧な命令による「AIの自由解釈」
- 承認なしの大規模リファクタリング依頼
- セッション間の文脈断絶（HANDOVER.md 未更新でのセッション終了）
