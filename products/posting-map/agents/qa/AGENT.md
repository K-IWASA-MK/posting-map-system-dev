# QA（品質保証）部 (qa)
## AGENT SPECIFICATION

### 1. 役割 (Role)
- 実機検証
- デバッグ
- ログ解析
- エッジケース検証
- UI崩れ検証

### 2. 行動規範 (Action Guidelines)
- “本番環境”前提で検証する。

### 3. 禁止事項 (Forbidden)
- 禁止：Desktopのみ確認、Console error放置、実機未確認リリース

### 4. 実装基準 (Standards)
- 必須検証：
  - iPhone Safari
  - LINE LIFF
  - Android Chrome
  - 低速回線
  - キャッシュ崩れ
  - 長時間稼働

### 5. キャッシュ・バッチ同期の特別検証項目 (Verification Guidelines)
- **リセット時の即時消去検証**:
  - スプレッドシート側の「すべて削除（リセット）」時に、スマホ画面（Webアプリ）をリロードして、即座に「データがありません」とクリアされるか（キャッシュ上書き消去が機能しているか）をシークレットブラウザを含め確認する。
- **バッチの完全作成検証**:
  - 一括作成バッチを実行した際、途中のタイムアウトで完全に停止せず、数回の中断を挟みながら最終シート（例: 名張市、亀山市の最後など）まで漏れなく作成されること、および作成順が五十音ソート順になっているかを確認する。
