# POSTING MAP Design System (SSOT)

本ドキュメントは、POSTING MAP 全体のUI・UX・ブランド・レイアウト・アニメーションの唯一のデザイン基準（Single Source of Truth）である。今後追加されるすべての画面、コンポーネント、モックアップ、およびプロモーションアセットは、本Design Systemに準拠しなければならない。

---

## 1. Brand Identity & Title Layout
正式ブランド名は **`POSTING MAP`** である。開発用コードネーム（Hアプリ、管理者アプリ等）は表に出してはならない。

### Dashboard Title Structure
ダッシュボードのタイトル表示は、以下のブランド名と組織名を組み合わせた2行構成を標準とする。
```text
POSTING MAP
────────────────────
[組織名] Dashboard
```
* 例: `POSTING MAP 三重第3支部 Dashboard`

---

## 2. Brand Color Palette (確定配色)
純黒ベースの高級感と、現場の活動を感じさせる明瞭なコントラストを定義する。

* **Primary (ブランドアクセント色)**: `#EA5F08` (オレンジ)
  * 用途: ブランドロゴ、Hover時の強調表示、Active状態、データポイントの発光 (Glow)、グラフのアクセント
* **Background (背景色 - Layer 1)**: `#0B0F14` (深みのある純黒)
* **Card (要素背景 - Layer 2)**: `#161B22` (ダークグレー)
* **Text (主要テキスト)**: `#FFFFFF` (白)
* **Secondary Text (副テキスト)**: `rgba(255, 255, 255, 0.65)` (淡い白)
* **Border (枠線)**: `rgba(255, 255, 255, 0.08)` (微細なエッジ線)

---

## 3. Dashboard Philosophy (設計哲学)
* **数字を見る画面ではない**: ダッシュボードは生データや数値を羅列して監視するためのものではなく、現場における「活動の流れ（Flow / Motion）」を視覚的に捉え、意思決定を支援するための画面である。
* **グラフと演出が主役**: 通常表示時はグラフ（Graph）やアニメーション（Motion）、時系列の活動状況（Flow）が最も目立つようにし、具体的な数値情報はユーザーのアクション（Hover）に応じてオンデマンドで提示する。

---

## 4. Layout & Responsibility (レイアウト設計)
* **Desktop (PC環境)**:
  * 1画面フィット型完結。全体縦スクロール禁止。
  * `height: 100vh; overflow: hidden;` を厳守し、動的なリスト内部のみをスクロール可能とする。
* **Mobile (スマホ環境)**:
  * 縦スクロール可。片手操作が前提の十分なタッチターゲットサイズ（48px以上）を確保する。

---

## 5. Navigation (左ナビゲーション構成)
PCダッシュボード左側には、以下のメニューを固定配置する。
1. **ダッシュボード** (Dashboard - 全体サマリー)
2. **保管者** (Custodians - チラシの分散保管状況)
3. **エリア** (Areas - 配布区域の進捗状況)
4. **活動ログ** (Activity Log - リアルタイム時系列ログ)
5. **活動分析** (Activity Analysis - 配布進捗や効率の分析)
6. **投票率** (Turnout - 市別投票率・対比)
7. **設定** (Settings - 連携設定)

---

## 6. KPI (主要業績指標)
ダッシュボード上部に配置する標準KPIカードは以下の3種類とする。
* **活動人数**: 現在稼働している配布員数。
* **新規活動人数**: LINE初回登録数と同一定義とする。
* **保有枚数**: 支部全体のチラシ在庫数。

---

## 7. Graph & Tooltip Rules (グラフ表示共通規則)
* **グラフはダッシュボードの主役**: 凡例や細かいグリッド数字は極限まで排除・透過し、曲線を美しく見せる。
* **Hover対応**: 折れ線・棒グラフ・その他すべてのグラフはHover時のみ詳細データを表示する。
* **Glass Tooltip (Apple風 Glassmorphism)**:
  * 半透明背景、Background Blur、角丸 (Radius 16px程度)、柔らかいドロップシャドウ、Pointer Arrow（矢印）付き。
* **Hover Point Glow**: Hoverされたデータポイントは、ブランドカラー（`#EA5F08`）で半径を拡大しアウターグロー（光彩）を発光させる。
* **Hover Line**: Hover位置に細い垂直ガイドライン（Vertical Guide Line）をオーバーレイ表示する。

---

## 8. Motion & Animations (モーション定義)
一切のカクつき（処理落ち）を許さず、GPUレンダリングを優先させた滑らかなトランジションを適用する。

* **Tooltip transition**:
  * Fade In (表示時): `200ms〜250ms` (Ease-out)
  * Fade Out (非表示時): `150ms` (Ease-in)
* **Point Glow transition**: `250ms` (データポイントの拡大と発光変化)
* **LIVE Indicator (稼働状況シグナル)**:
  * 激しい点滅を禁止し、ゆっくり呼吸するような明滅（Pulse アニメーション）を適用する。
* **Rolling Number (ローリングエフェクト)**:
  * KPIカード等の数値更新時、ドラムロールのように数字が回転して滑らかに増減する（Odometer効果）。
* **新着活動ログの演出**:
  * ログが新規追加された瞬間、カードの境界線を3秒間だけブランドカラー（`#EA5F08`）でネオン風に発光（Glow）させ、徐々に通常カードへと同化させる。

---

## 9. Card Style (コンテンツコンテナ)
すべてのUI要素カードは極上ガラスUI (Glassmorphic Container) に統一する。
* **仕様**:
  * 角丸: `border-radius: 20px;` (UI固定ルール優先)
  * 背景: `#161B22` (微透過)
  * 効果: `backdrop-filter: blur(20px);`
  * 境界: 柔らかい極細エッジボーダー (`1px solid rgba(255, 255, 255, 0.08)`)
  * 影: やわらかな拡散シャドウ

---

## 10. Typography Rules (フォントと文字階層)
* **Title (タイトル)**: Bold (太字)
* **KPI Number (主要数値)**: Extra Bold (極太) - 数字を最も巨大にし目立たせる。
* **Body / Description (本文・説明)**: Regular (標準) - 文字サイズを小さく設定し、コントラストを強調。

---

## 11. Chart Display Rule (表示非表示原則)
* **通常時**: 数字を画面上にできるだけ表示せず、ビジュアル要素（色、グラフ線、比率）のみで感覚的に状況を伝える。
* **Hover時**: マウスが合わさった瞬間のみ詳細データをGlass Tooltipで即座に提示する。

---

## 12. Mission Control Rule
* **意思決定支援（ミッションコントロール）**: 本システムは、一般的なビジネスダッシュボード（データテーブルの羅列や分析ツールの塊）ではない。
* 現場全体のオペレーション状況を「一瞬で把握できる管制塔（Mission Control）」として設計する。

---

## 13. UX Rule (ノンマニュアル設計)
* 画面を開いた瞬間に状況が理解できる直感性を提供する。
* 操作についての説明文は不要、操作マニュアルも不要とし、ユーザー（特に高齢の配布員や支部長）が迷う余地を一切残さない設計とする。

---

## 14. Product Philosophy (プロダクトの存在意義)
* **チラシ管理・監視の撤廃**: POSTING MAPは「配布員を管理・監視するシステム」ではない。
* **自発的活動のプラットフォーム**: 誰が、どこで、何枚のチラシを保有しているかを可視化することによって、ボランティア活動への参加障壁を下げ、地域活動の自発的開始を滑らかにするマッチングインフラである。

---

## 15. Absolute Rule (絶対不可侵)
今後追加されるすべての Dashboard、Mobile PWA、Canvaデザイン、操作マニュアル、LP、および広報用Webサイトは、例外なく本Design Systemに準拠しなければならない。本ガイドラインから逸脱した独自のUIや装飾は一律禁止とする。

---

## 16. Human Engineering Rule (プロフェッショナルエンジニアポリシー)
AIによる画一的なUI出力を厳しく禁止し、経験豊かなシニアエンジニアおよびデザイナーが時間をかけて磨き上げた品質（Human Craftsmanship）を実装目標とする。

* **AIテンプレートレイアウトの禁止**: 均一サイズの単調なカード配置、無意味なグラデーション、機械的に情報をグリッドに流し込むだけのレイアウトは「AI臭」の原因となるため排除する。
* **情報のコントラストと視線誘導**: 画面全体の重要度に応じて余白（マージン・パディング）に強弱をつけ、グラフを主役とし、数字は補助的に見せる「引き算のデザイン」を行う。
* **完成を急がない（ディテール調整）**: 余白の数ピクセルのブレ、グラフ線の強弱、Hover時のスムーズさなど、操作時に少しでも違和感を覚える部分は何度もミリ単位で微調整し、毎日使いたくなるレベルへ磨き上げる。
