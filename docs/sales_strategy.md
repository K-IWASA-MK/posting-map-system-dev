# POSTING MAP 営業・マーケティング戦略書
## コンセプト：「見えない無駄を、お金と票に変える！」

本ドキュメントは、政治・現場統制OS「POSTING MAP」を政党県連や衆院小選挙区の候補者に売り込むための、最強の営業戦略・価格合理性のロジックをまとめたものである。今後のシステム開発においても、このビジネスモデルを常に念頭に置いて設計を行う。

---

## 1. 核心的キャッチフレーズ

> **「見えない無駄を、お金と票に変える！」**
> 〜 放置された「低投票率エリア」を耕し、未開拓の票を総ざらいする 〜

---

## 2. 圧倒的な差別化強み（有権者の掘り起こし）

競合のポスティング業者や一般の地図アプリは、単なる「世帯数」や「人口密度」に基づいた配布効率しか見ていない。しかし、選挙における勝利の鍵は、**「まだ態度が決まっていない眠れる有権者の獲得」**にある。

*   **高投票率エリアの現状**: 
    すでに政党の組織票や固定票で固まっており、他陣営が割って入る余地（新規獲得）は極めて少ない。
*   **低投票率エリアのポテンシャル（ブルーオーシャン）**:
    他の陣営は「どうせ投票に行かない」と決めつけ、ビラ配りすら行わず放置している。ここには大量の「無党派層・浮動票」が眠っている。
*   **POSTING MAPの提供価値**:
    直近の選挙での**「投票区別・町丁別の投票率」を地図上にオーバーレイ表示（可視化）**する。
    これにより、ライバルが放置した「低投票率エリア」へボランティアや信頼できる配布員をピンポイントで投入し、自陣営だけの新規の票を総ざらいして投票率を底上げする。

---

## 3. 政治資金収支報告から突き崩すROI（費用対効果）

年間でチラシ（ビラ）を **50万枚** 配布する小選挙区支部（候補者1名）のコストシミュレーション。

| 項目 | 対策なし（従来の無駄） | POSTING MAP導入後 | 削減効果（浮くお金） |
| :--- | :--- | :--- | :--- |
| **① 印刷費** (50万枚×3円) | 150万円 (無駄30% = 45万円) | 105万円 | **＋45万円**（無駄なデッドストックの削減） |
| **② 配送・仕分け費** | 50万円 (無駄40% = 20万円) | 30万円 | **＋20万円**（在庫管理による無駄な横持ち・配送のカット） |
| **③ 配布外注・人件費** | 350万円 (無駄40% = 140万円) | 210万円 | **＋140万円**（GPSトラッキングによる手抜き・投棄・重複配布の防止） |
| **合計** | **550万円** | **345万円** | **＋205万円のコスト削減** |

### 💰 実質的なシステム導入コスト
本システムの価格設定：**「初期費用100万円 ＋ 月額10万円（年間120万）＝ 年間総額 220万円」**

*   印刷・物流・配布の『見えない無駄』をカットするだけで年間 **205万円** が削減されます。
*   したがって、年間220万円のシステム利用料は**「実質年間わずか15万円」**の負担で導入できる計算になります。
*   さらに、未開拓の低投票率エリアの掘り起こしによる**「数千票の新規獲得（＝当選確率の劇的向上）」**という、価格を遥かに超えるリターンをもたらします。

## 4. 決裁者を動かすキラー営業トーク

> 「代表、昨年の収支報告書を拝見しました。宣伝事業費に1,000万円以上使われていますね。
> 
> 実態として、そのうちの少なくとも『300万円分』は、配られずに物置に眠ったままのチラシ、業者が配ったと言い張るだけで実際には捨てられたビラ、そして同じ地域に何度も重ねて配られた重複の無駄です。
> 
> POSTING MAPを導入すれば、GPS軌跡ログとリアルタイム在庫管理によって、その300万円のドブ捨てをピタッと止められます。浮いたお金でシステム代金（年間220万）は完全にお釣りが来ます。
> 
> そして何より、**ライバルが『どうせ行かない』と放置している低投票率のフロンティアへ攻め込み、眠っている有権者を代表のメッセージで叩き起こしましょう。誰も手を付けていない地域をあなただけの『新規の票』に変える。**
> 
> お金を節約しながら、票を最大化して確実に勝つための唯一無二のOSです。」
