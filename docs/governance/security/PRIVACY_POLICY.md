# POSTING MAP 利用規約およびプライバシーポリシー

本規約およびポリシーは、政治・現場統制OS「POSTING MAP」（以下「本サービス」）において、配布活動および保有情報の管理に伴い取得される個人情報その他の情報の取り扱いを定義するものです。

---

## 1. 取得する情報

本サービスでは、利用者が活動報告または保有情報の更新を行う際、以下の情報を取得・記録します。

1. **LINE認証情報**: 利用者アカウント識別、LINE LIFF 連携用識別子。
2. **スタッフ識別番号 (スタッフID)**: 組織内の活動員を一意に特定するための内部識別子。
3. **写真（エビデンス）**: 活動状況の証跡としてアップロードされる写真。
4. **GPS位置情報**: 配布活動報告時に記録される経度・緯度。
5. **端末情報**: 利用端末の OS バージョン、ブラウザ種別等。
6. **活動日時**: 保有情報の申告日時、および活動報告が行われた日時。
7. **活動報告内容**: 利用者が報告した配布枚数、状況説明等のテキスト。

---

## 2. データの利用目的

取得したデータは、以下の目的のために利用され、それ以外の目的には利用されません。

1. **活動報告の記録**: 配布活動の客観的証跡としての保存。
2. **活動状況の可視化**: 支部ダッシュボード上でのリアルタイムな配布進捗の把握。
3. **ランキング表示**: ボランティアスタッフ間の配布枚数ランキングを通じた活動意欲（モチベーション）の向上。
4. **不正報告防止**: 重複報告、虚偽報告の防止および整合性の検証。
5. **サービス品質向上**: 現場の操作性改善や障害検知のためのシステム分析。

---

## 3. 保存期間およびデータ削除方針

1. **保存期間**:
   取得した写真およびGPS位置情報等の活動記録は、本サービスを利用する Workspace 契約期間中、または利用目的の達成に必要な期間保存されます。
2. **削除方針**:
   契約終了時、または利用目的が達成された後は、復元不可能な方法で速やかに削除されるか、または個人を特定できない形で適切に管理されます。

---

## 4. 利用・共有の範囲

1. **契約支部（Workspace）限定**:
   利用者の活動情報は、参加している契約支部（Workspace）の運営管理および活動確認のみに利用されます。「本部」等の一元化された中央サーバーで外部公開されたり、他支部へ横断的に提供されたりすることはありません。
2. **アクセス権限の制御**:
   GPS位置情報や写真などの詳細な活動証跡データは、セキュリティ上の観点から、Workspace 内の必要な権限を持つ管理者（支部長等）のみが閲覧でき、一般利用者は他人の詳細な証跡を閲覧することはできません。

---

## 5. 技術・ドメイン分離の原則（アーキテクチャ固定ルール）

本ポリシーの運用を担保するため、本サービスは以下のドメイン分離を厳格に順守して設計されます。

* **活動記録レイヤー (GPS位置情報・写真証跡)**:
  - 活動報告（配布完了、活動状況）の信頼性を検証するためにのみ利用されます。
  - 在庫管理、チラシの割り当て、自動減算ロジックには一切紐付けられず、混在させません。
* **自己申告レイヤー (保有情報・枚数)**:
  - 保有チラシの管理は、すべて配布員本人の「自己申告」による現在保有枚数の記録（`FlyerStock`）に基づいて行われます。
  - 連絡用リクエスト（`PickupRequest`）が発生しても、システムによる自動減算や引当は一切実行されません。
