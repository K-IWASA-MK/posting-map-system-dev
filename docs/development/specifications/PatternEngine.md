# パターンエンジン仕様書 (Pattern Engine Specification)

## 目的
AIOS（品質保証オペレーティングシステム）において、改善履歴（Improvement History）やレビューログのデータ群を解析し、品質のデグレードを招いた原因（アンチパターン）や、劇的な品質向上（Deltaの最大化）をもたらした有効な修正手法を「再現可能なパターン」として抽出する「パターンエンジン（Pattern Engine）」の仕様を定義する。

---

## 責務
- **改善パターン抽出 (Improvement Pattern Extraction)**: 修正されたソースコードの AST 差分やテキスト変更特徴から、汎用化可能な構造パターンを特定。
- **レビュー傾向分析**: スプリントをまたいで、どのようなルール違反（例: Thin Frontend原則）が多発しているかの統計分析。
- **品質変化分析**: 各モジュールの修正が、どのカテゴリのスコア向上に寄与したかを時系列で追跡。
- **AI Smell 発生傾向分析**: 生成AIがどのようなコードやUIコンポーネントを作成した際に「AI Smell Level 2/3」が発生しやすいかの因果関係を抽出。
- **成功パターン抽出 (Success Patterns)**: 適用後に品質スコアの Delta がプラスとなり、かつ `Re-Review` で一発合格した「黄金の修正パターン」の特定。
- **失敗パターン抽出 (Failure Patterns)**: 適用後にデグレードを招くか、ビルドエラーを発生させ、結果的にロールバック（Rollback Strategy）を引き起こした「アンチパターン」の特定。

---

## パターン分析モデル (Pattern Analysis Model)
パターンエンジンは、以下の判定テーブルに従って成功・失敗パターンを分類する。

| 改善量 (Delta) | 再レビュー判定 | 分類カテゴリ | アクション |
|---|---|---|---|
| **Delta >= 10.0** | PASS | 顕著な成功 (Success Pattern) | ナレッジ候補（Candidate）へ即時推薦。 |
| **Delta >= 0** | PASS | 通常の成功 (Standard Solution) | 履歴に蓄積し、類似問題検知時の解決策候補とする。 |
| **Delta < 0** | FAIL (デグレード) | 失敗アンチパターン (Failure Pattern) | 今後の改善計画立案（Planner）時の禁止リストに登録。 |
| **ビルドエラー発生** | - | 重大な失敗 (Critical Failure Pattern) | ロールバック実行と、失敗パターンの即時ブラックリスト化。 |
