# ポーリング制御仕様書 (Dashboard Polling Specification)

## 概要 (Overview)
本仕様書は、AIOS Dashboard における定期的な読み取り専用データ取得サイクル（Polling）および障害発生時の耐障害性・再試行（Retry）制御を規定する。

---

## ポーリング制御パラメータ (Polling & Timing Parameters)
- **定期取得間隔 (Polling Interval)**:
  - 通常：`10000ms` (10秒間隔での GET 呼び出し)
  - デバッグ検証時：`5000ms`
- **通信タイムアウト (Timeout Limit)**:
  - 1 回のリクエストあたり `5000ms` の Timeout を設定。
- **再試行ポリシー (Exponential Backoff & Retry)**:
  - 通信障害または例外発生時、高速な再リクエストのループを防止するため、指数バックオフを適用する。
  - 初期再試行間隔：`2000ms`
  - 乗数：`2.0` (毎回倍増: 2s -> 4s -> 8s -> 16s -> ...)
  - 最大再試行間隔：`60000ms` (1分)
- **状態復旧検出**:
  - バックオフ中または障害時であっても、GET 通信が正常完了した時点で LIVE 状態へ自動復帰し、ポーリング間隔は通常の間隔（10秒）にリセットされる。

---

## 隔離境界と安全要件 (Security Boundaries)
- **無限高速リトライの禁止**:
  - 通信断絶時にミリ秒単位での再接続要求を行ってはならない。
- **書込み・状態変更の禁止**:
  - ポーリングサイクルの中で、`POST`, `PUT`, `PATCH`, `DELETE` などの API 書込みメソッドを呼び出すことは厳禁である。
