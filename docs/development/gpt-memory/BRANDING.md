# POSTING MAP Brand Identity (SSOT)

本ドキュメントは、POSTING MAPにおける製品ブランド設計、構成、および命名規則に関する**不変の固定仕様（永続ルール）**である。今後のすべてのUI・営業資料・マニュアル・実装はこの定義を前提としなければならない。

---

## 1. Product Brand
- 本プロダクトの正式ブランド名は **`POSTING MAP`** とする。
- 今後、Hアプリ等の開発コードネームは使用せず、利用者向けにはすべて「POSTING MAP」の名称へ統一する。

---

## 2. Product Structure
POSTING MAP は以下の2製品で構成される。

### ① POSTING MAP Mission Control
- **定義**: PC向け管理・統制管制システム（一般呼称: Dashboard）。
- **対象ユーザー**: 支部長、県連管理者、ブロック管理者、本部管理者。
- **仕様**: Dashboardは唯一の共通エンジンとし、Scopeパラメータ（支部・県連・ブロック・本部）を切り替えることで表示を制御する。単なるデータ監視用の「ダッシュボード」ではなく、現場の鼓動を可視化する「Mission Control」として構築する。

### ② POSTING MAP
- **定義**: スマートフォン向けWebアプリ。
- **対象ユーザー**: 党員、サポーター、ボランティア。
- **仕様**: 近くの保管者からのチラシ受け取り申請から、活動終了時の実績報告までを支援する。
- **注意**: 利用者に対して「Hアプリ」という名称は一切使用しない。

---

## 3. Dashboard Naming Rule
Dashboardのタイトル表示は、以下の命名規則を厳密に遵守して構成する。この規則を変更してはならない。

```text
[ブランド名]
──────────────────
[組織名] Dashboard
```

### 構成例:
*   **支部レベル**:
    ```text
    POSTING MAP
    ──────────────────
    三重第3支部 Dashboard
    ```
*   **県連レベル**:
    ```text
    POSTING MAP
    ──────────────────
    三重県連 Dashboard
    ```
*   **ブロックレベル**:
    ```text
    POSTING MAP
    ──────────────────
    東海ブロック Dashboard
    ```
*   **本部レベル**:
    ```text
    POSTING MAP
    ──────────────────
    本部 Dashboard
    ```

---

## 4. Brand Philosophy & Kickoff Vision
POSTING MAP は、**「誰が・どこで・何枚チラシを保有しているか（在庫の可視化）」**を最優先で可視化し、ノルマ管理ではなく、**「ボランティアが自発的に活動へ参加できる環境を提供する」**ことを最大の存在意義（ブランドフィロソフィー）とする。

#### 【プロダクトの魂（スプリントキックオフ・メッセージ）】
> **「POSTING MAPは、画面を表示するソフトウェアではない。人の『活動したい』という気持ちを、『今すぐ活動できる』へ変えるプロダクトである。すべてのUI、余白、動き、色、アニメーションは、その一歩を自然に後押しするために存在する。」**

---

---

## 5. UI Branding Rule & Absolute Rule
- **ブランド表記の統一**: 
  - スマホアプリ ➔ **`POSTING MAP`**
  - PC管理画面 ➔ **`POSTING MAP [○○] Dashboard`**
  として全国でブランド表記を統一する。
- **開発コードネームの排除**:
  - 以下の名称は開発コードとしてのみ扱い、**利用者向け画面・マニュアル・営業資料・メールテンプレートでは絶対に使用しない（厳禁）**。
    - ❌ `H-App` / `Hアプリ` / `フィールド端末（H-App）`
    - ❌ `管理者アプリ` / `ADMIN PANEL`
  - 利用者向け名称はすべて **`POSTING MAP`** または **`POSTING MAP Dashboard`** へ統一する。
