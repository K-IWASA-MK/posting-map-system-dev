# 品質スコアモデル定義書 (Score Model Specification)

## 目的
AIOS（品質保証オペレーティングシステム）において、各レビューカテゴリの評価項目と、それに基づくスコア、重み、ステータス、改善優先順位の算定モデルを定義する。

---

## 評価カテゴリとパラメータ定義

各レビューカテゴリは、以下のパラメータに基づいて詳細に評価・構造化される。

### 評価パラメータ
1. **スコア (Score)**: カテゴリ内の検証項目に対する適合率（0〜100点）。
2. **比重 (Weight)**: 総合スコアに与える影響割合（パーセンテージ）。
3. **状態 (Status)**: 合否判定（`PASS` / `WARNING` / `FAIL`）。
4. **改善優先順位 (Priority)**: 修正を実行すべき緊急度（`P0` / `P1` / `P2` / `P3`）。
5. **優先理由 (Reason)**: 優先順位（Priority）が決定された具体的なルール違反やAI臭レベルなどの根拠。
6. **改善推奨 (Recommendation)**: 検出された問題点を解消するための具体的なアクション指示。

---

## 改善優先順位 (Priority) 定義規律
スコアの点数の高低だけでなく、以下の基準に合致した場合は強制的に高い優先順位（Priority）が割り当てられる。

- **P0 (即時対応必須 - リリース不可)**:
  - `Architecture` カテゴリで重大な階層分離違反（例: フロント側のDB直接依存）が発生した場合。
  - `AI Smell` カテゴリで Level 3（重大な情報過多・視線誘導崩壊）が検出された場合。
- **P1 (優先対応推奨 - リリース不可)**:
  - `Human Engineering` カテゴリで「第0原則」（迷わせない導線）に違反していると判定された場合。
  - `AI Smell` カテゴリで Level 2（均等グリッド・テンプレート感）が検出された場合。
- **P2 (通常対応 - 条件付きリリース可)**:
  - `Design` カテゴリで部分的な色・余白のズレがある場合。
  - `Output` カテゴリで日本語優先ルールに部分的な漏れ（不要な英語タグの残存）がある場合。
- **P3 (軽微・推奨 - リリース可)**:
  - 細部のアニメーションのイージングのわずかなブレや、ドキュメントの表記揺れ。

## カテゴリ別評価項目

### 1. アーキテクチャ (Architecture)
- **評価項目**: 責務分離、Layer Separation、Thin Frontend原則、GASのビジネスロジック集中、Single API原則。
- **標準比重**: 15%

### 2. 仕様機能 (Product)
- **評価項目**: 要求仕様のカバー率、Mission Control思想（最重要数値の最上部配置）、ブランド一貫性。
- **標準比重**: 15%

### 3. 人間工学 (Human Engineering)
- **評価項目**: 第一印象（3秒ルール）、視線誘導（Flow）、生命感（Emotion）、職人品質（Craftsmanship）、同一性（Identity）。
- **標準比重**: 15%

### 4. 意匠デザイン (Design)
- **評価項目**: タイポグラフィ（Typography）、カラーパレット（Color）、余白（Spacing）、レイアウト（Layout）、ガラスUI（Glass）、アニメーション速度（Motion）。
- **標準比重**: 10%

### 5. ユーザー体験 (UX)
- **評価項目**: 第0原則（直感的導線）、ユーザー行動の短縮（親指ゾーン、タップ数最小化）、情報密度の最適化。
- **標準比重**: 10%

### 6. 実行時性能 (Runtime)
- **評価項目**: クライアント側の描画性能、APIコール数、送受信JSONサイズ、アニメーションのフレームレート（60fps維持）。
- **標準比重**: 10%

### 7. 出力制御 (Output)
- **評価項目**: 日本語品質、構成の統一、コピー性、不要な英語表現の排除。
- **標準比重**: 10%

### 8. AI臭検出 (AI Smell)
- **評価項目**: 均等グリッド、均一なカード配置、テンプレート感、過剰なグラデーション/Glow、管理画面感。
- **標準比重**: 15%
