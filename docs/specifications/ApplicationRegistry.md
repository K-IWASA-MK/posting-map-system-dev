# Application Registry 仕様書

## 概要
本仕様書は、プラットフォーム上にプロビジョニングされ、アクティブに稼働するアプリケーションの管理ルールを規定します。

## 主要機能
- **パッケージインポート登録**:
  - `ApplicationDefinition` および `ApplicationManifest` を紐付け登録し、完全性を保証します。
- **バージョン管理とロールバック**:
  - バージョン履歴を保持し、障害発生時または計画キャンセル時には以前のアクティブバージョンへのロールバックをサポートします。
- **環境設定の切替**:
  - `ApplicationProfile` に基づき、ターゲット環境（開発・本番など）に応じて動的な実行ポート・設定変数の切替解決（Application Resolver）を提供します。
