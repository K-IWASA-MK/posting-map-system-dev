# Service Registry 仕様書

## 概要
本仕様書は、プラットフォーム内にインストールされたサービス登録状態、およびメタデータ情報の格納ルールを規定します。

## 主要機能
- **インストール登録**:
  - `ServiceDefinition` と `ServiceIdentity`（証明書ID、マニフェストハッシュ）を紐付けして保存します。
- **署名完全性検証**:
  - パッケージの完全性を検証し、署名検証に失敗したサービスは登録されません。
- **ディスカバリ検索**:
  - `IRuntimeService` ディスカバリと同様に、提供 Capabilities を基準として対象サービスを動的に解決できます。
