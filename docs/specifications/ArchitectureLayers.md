# アーキテクチャレイヤー定義 (Architecture Layers)

## 概要
本仕様書は、AIOS プラットフォームにおける標準的なレイヤー階層構造と、各レイヤーが担うべき責務およびデータの流れ（データフロー）を定義します。

## レイヤー構造
AIOS は以下の5つの主要レイヤーで構成され、上位レイヤーから下位レイヤーへの一方向の呼び出しのみが許可されます。

```
+---------------------------------------------------+
|               Applications (アプリケーション層)    |
+---------------------------------------------------+
                          |
                          v
+---------------------------------------------------+
|               AIOS SDK (公開インターフェース層)    |
+---------------------------------------------------+
                          |
                          v
+---------------------------------------------------+
|               Capabilities (機能・サービス提供層) |
+---------------------------------------------------+
                          |
                          v
+---------------------------------------------------+
|               Runtime (システム実行基盤層)         |
+---------------------------------------------------+
                          |
                          v
+---------------------------------------------------+
|               Kernel / Core (最下位OSコア層)       |
+---------------------------------------------------+
```

## 各レイヤーの責務

### 1. Kernel / Core (最下位OSコア層)
- **役割**: プラットフォームの最も基礎的な機能を担います。
- **責務**: ファイルシステムの抽象化、プロジェクトの探索・ライフサイクル管理、基本ユーティリティ、システム定数の定義。
- **依存関係**: 他のいかなるレイヤーにも依存してはなりません（純粋な独立層）。

### 2. Runtime (システム実行基盤層)
- **役割**: システムの実行およびメッセージング制御を行います。
- **責務**: `RuntimeEventBus` による非同期イベント通信、`RuntimeLedger` による不変イベントログの記録、タスクスケジューラ、モニタリング機能。
- **依存関係**: `Kernel / Core` レイヤーにのみ依存可能です。

### 3. Capabilities (機能・サービス提供層)
- **役割**: 特定のシステム機能や統合サービスを提供します。
- **責務**: 認証管理（Security）、変更監査（Audit）、最適化エンジン（Optimization）、外部連携等のプラグインサービス。
- **依存関係**: `Kernel` および `Runtime` レイヤーに依存可能です。

### 4. AIOS SDK (公開インターフェース層)
- **役割**: 外部アプリケーション向けの唯一のゲートウェイです。
- **責務**: 公開インターフェースの提供、データ転送オブジェクト (DTO) の定義、内部エラーの安全なラップ、安定したAPIの露出。
- **依存関係**: `Capability`, `Runtime`, `Kernel` の各サービスをラップして提供します。

### 5. Applications (アプリケーション層)
- **役割**: エンドユーザー向けの業務ロジックや画面を提供します。
- **責務**: ユーザーインターフェース (UI) の構築、ドメインロジックの実装、SDKを利用したシステム機能の呼び出し。
- **依存関係**: **AIOS SDK レイヤーにのみ**依存できます。内部レイヤーへの直接参照は一切禁止されます。

## データフロー規則
- **制御の流れ (Control Flow)**: 常に上位から下位（Application -> SDK -> Core）へと流れます。
- **イベントの流れ (Event Flow)**: 下位で発生した状態変化やシステムイベントは、`RuntimeEventBus` を介して上位（Application / Monitor）へ通知されます。上位コンポーネントはイベントリスナーを通じてこれらを受信します。直接的なコールバックの逆流は禁止されます。
