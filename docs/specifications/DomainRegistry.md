# Domain Registry 仕様書

## 概要
本仕様書は、外部信託ドメインの情報、およびアクティブなフェデレーションセッションを管理するレジストリの仕様を定義します。

## 管理対象データ
1. **ドメインプロファイル (Domain Profile)**:
   - 外部ドメインの一意な ID、ドメイン種別（SaaS, CLOUD 等）、接続通信プロトコル、信託レベル（trustLevel）。
2. **接続セッション (Federation Session)**:
   - 動的なセッションID、相互認証状態（mutualAuthStatus）、およびセッションの有効期限。セッションが終了（TERMINATED）された場合、対応する信頼スコアのキャッシュは即座に無効化されます。
