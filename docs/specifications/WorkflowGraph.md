# Workflow Graph 仕様書

## 概要
本仕様書は、ワークフローを構成するノード間の依存トポロジー（有向非巡回グラフ - DAG）のバリデーション規則およびソートアルゴリズムを規定します。

## アルゴリズムと検証規則
1. **循環検出 (Cycle Detection)**:
   - 登録されたエッジとノードから隣接リストを生成し、トポロジカルソートを実行します。訪問完了したノードの総数が全体のノード数と一致しない場合、循環参照（ループ）が存在すると判定して検証を拒否します。
2. **孤立ノード検出 (Isolated Node Detection)**:
   - 入次数 (inDegree) と出次数 (outDegree) がともに 0 であるノードが存在し、かつノード総数が 2 以上である場合、そのノードは「孤立ノード」とみなし、エラーとして弾きます。
3. **到達可能性検証**:
   - `entryNode` から `exitNode` への有効な経路が必ず 1 つ以上存在することを保証します。
