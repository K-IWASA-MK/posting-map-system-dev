# Process Execution (サンドボックスプロセス実行仕様書)

## 概要
サンドボックスプロセス実行エンジンは、イメージメタデータおよびセキュアなシークレット隔離ポリシーに沿って、実際のOS環境にプロセスをバインド・起動・終了します。

## 機密隔離状態遷移 (SecretState)
認証情報や鍵（Secret）は、シェル環境に直接書き込まれず、コンテナ内で以下の状態遷移を経て隔離管理されます。

- **REGISTERED**: シークレットレジストリ（SecretBroker）に格納された状態。
- **AUTHORIZED**: 呼び出し対象プロセスがシークレット参照を許可された状態。
- **INJECTED**: 暗号化された形で、または必要なセキュアメモリ空間へのみ注入された状態。
- **REVOKED**: シークレットの有効期限切れ、または権限剥奪。
- **DESTROYED**: 実行空間の消滅またはメモリワイプによる完全消去。
