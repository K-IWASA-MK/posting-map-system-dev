# Security Policy 仕様書

## 概要
本仕様書は、AIOS プラットフォームにおける機密管理ルールおよびゼロトラスト（Zero Trust）ポリシーの設計基準を規定します。

## セキュリティ設計三原則
1. **セキュリティファースト (Security First)**:
   - システム全体の可用性や速度よりも、安全な実行境界の隔離が優先されます。
2. **最小特権原則 (Least Privilege)**:
   - すべてのプラグインおよびコンポーネントは、タスク実行に必要最小限の権限のみを一時的に付与される `CapabilityToken` の制限下で稼働しなければなりません。
3. **シークレット仲介 (Secret Brokerage)**:
   - データベース鍵やAPIキーなどの機密（Secret）は、Security Runtime の Secret Broker による明示的な認可チェックを通過しない限り、取得・参照できません。
