# Signature Verification 仕様書

## 概要
本仕様書は、AIOS プラットフォームにおける実行主体および外部リクエストに対するデジタル署名の暗号検証基準を規定します。

## 署名検証プロセス
1. **公開鍵の解決**:
   - リクエストに付与された `identityId` に基づき、対応する `DigitalIdentity` を解決します。
2. **有効性検証**:
   - `DigitalIdentity` のステータスが `VERIFIED` であり、かつ紐付く `Certificate` のステータスが `ACTIVE`（かつ有効期限内）であることを検証します。
3. **署名適合チェック**:
   - 対象のペイロードデータと署名値が、証明書の公開鍵を用いて正常に復号/整合チェックをクリアすることを確認します。
4. **監査イベント**:
   - 署名検証の結果（成功/失敗）は `SignatureVerified` イベントとしてパブリッシュされ、証跡記録に追加されます。
