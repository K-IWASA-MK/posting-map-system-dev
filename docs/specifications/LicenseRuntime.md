# License Runtime 仕様書

## 概要
本仕様書は、サービスの利用権限、ライセンスの発行、および契約有効期間の監査を行う「License Runtime」の仕様を定義します。

## ライセンス状態遷移 (License State Machine)
ライセンスレコードは以下の状態を遷移します：
`ISSUED` (発行) ➔ `ACTIVE` (有効) ➔ `SUSPENDED` (一時停止) ➔ `REVOKED` (失効) ➔ `EXPIRED` (期限切れ)

## 検証とキャッシュポリシー
- **期限チェック**: 期限切れ日付（expiresAt）が現在時刻以下になった時点で、自動的に `EXPIRED` と判定されます。
- **認可連携**: Security Runtime はリソースへのアクセスを認可する前に本ランタイムに問い合わせ、状態が `ACTIVE` 以外のものはすべて認可拒否（DENY）します。
- **ライセンスキャッシュ**: パフォーマンス向上のため短時間のメモリキャッシュを行い、失効イベント（REVOKED）受信時にはキャッシュを即座に無効化（Evict）します。
