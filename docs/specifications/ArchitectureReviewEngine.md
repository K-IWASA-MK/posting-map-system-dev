# アーキテクチャレビューエンジン仕様書 (Architecture Review Engine Specification)

## 目的
AIOS（品質保証オペレーティングシステム）において、本番環境の動作安定性と保守性を担保するため、システムの階層構造およびコンポーネント間の依存関係を厳格に監査する「アーキテクチャレビューエンジン（Architecture Review Engine）」のルールおよび制約を定義する。

## レビュー対象・統制ルール

### 1. レイヤーの分離 (Layer Separation)
システムは以下のデータフローおよび依存関係の方向を厳守しなければならない。依存関係は一方向であり、逆方向の依存（例: データベースからビジネスロジックへの直接参照、またはプレゼンテーションからデータソースへの直接アクセス）は禁止する。

```
[Data Layer (Spreadsheet)] ──> [Business Logic Layer (GAS)] ──> [Presentation Layer (Frontend)]
```

### 2. 薄いフロントエンド原則 (Thin Frontend Rule)
フロントエンド（クライアント側JavaScript/HTML）は、純粋なユーザーインターフェースの描画とインタラクションのみを担当し、ビジネス上の判断やデータの構造的処理を行ってはならない。

- **禁止事項 (Forbidden)**:
  - 複雑なビジネスロジック（配布員のステータス変更条件などの判定処理）の記述。
  - 生データの集計や統計処理。
  - データベース（Spreadsheet等）への直接的な依存や、GASを介さない接続。
- **フロントエンドの責務 (Responsibilities)**:
  - レンダリング (Render) - APIから受信したJSONデータの描画。
  - アニメーション (Animation) - 画面遷移や発光・フェード・トランジション効果。
  - インタラクション (Interaction) - ボタンタップ、入力フォームのイベント処理。

### 3. スプレッドシートの純粋性 (Spreadsheet Purity)
スプレッドシート（Spreadsheet）はデータストレージとしての役割に限定されなければならず、ロジックや高度な計算を含んではならない。

- **禁止事項 (Forbidden)**:
  - スプレッドシート内でのグラフ・図表生成。
  - `QUERY` 関数や `FILTER` 関数の乱用（複雑な数式によるデータ抽出）。
  - 合計、平均、アクティブ配布員数などのデータ集計・統計処理。
  - ビジネスロジック（権限や状態の判定など）をセルの数式で実装すること。

### 4. GASの責務 (GAS Responsibility)
Google Apps Script (GAS) は、データベース（Spreadsheet）とフロントエンドの仲介として、すべてのビジネスロジックとデータ加工を一手に引き受ける。

- **GASの責務 (Responsibilities)**:
  - データの集計・統計処理。
  - ビジネスロジックの評価と状態遷移の管理。
  - フロントエンドへ返却する、スキーマに準拠したクリーンなJSONデータの生成。
  - 入力値の検証 (Validation)。

### 5. シングルAPI原則 (Single API Rule)
フロントエンドが複雑な画面を描画する際、複数のAPIを個別に叩いてクライアント側でマージすることを防ぐ。
- **制約 (Rule)**:
  - 管理者ダッシュボード（Dashboard）などの統合画面は、単一のAPIエンドポイント `GET /dashboard` を呼び出すだけで、画面構成に必要なすべての集計JSONデータが一度に取得でき、それのみで完全な描画が可能でなければならない。
  - 画面描画のために、`getUsers`, `getSummary`, `getAreas` などのAPIを個別に同時コールして結合する処理をフロントエンドに実装することを禁止する。

### 6. 実行環境の分離 (Runtime Separation)
開発環境、ステージング環境、本番環境の各ランタイムにおいて、リソースの依存関係は一方向にのみ分離されていなければならない。

- **制約 (Rule)**:
  - **Spreadsheet ──> GAS ──> Frontend** の順にのみ参照され、Frontendが特定のデータベースID（Spreadsheet ID等）を直接保持したり、GASがFrontendの特定の要素やHTML構造に依存した動作を行ったりすることを禁止する。
  - APIの入出力インターフェース（JSONスキーマ）のみが両者の契約（Contract）であり、双方は完全に独立してデプロイおよび実行可能でなければならない。
