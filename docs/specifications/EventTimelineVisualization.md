# Event Timeline Visualization Specification (EventTimelineVisualization.md)

## 1. 重要度に応じたマーカー表示仕様 (Severity Visual Markers)
タイムラインの各ノード（マーカー）は、重要度（Severity）に基づいて以下の配色とエフェクトで描き分ける。

* **CRITICAL**:
  * マーカー表現: 🔴 (Red Marker)
  * ビジュアルエフェクト: 赤色の微発光パルス Glow 効果（シャドウによる微光）を付与し、注意を引きつける。
* **WARNING**:
  * マーカー表現: 🟠 (Orange Marker)
  * ビジュアルエフェクト: オレンジ色の塗りつぶし円。
* **INFO**:
  * マーカー表現: ⚪ (White / Gray Marker)
  * ビジュアルエフェクト: 透過枠線付きの白い丸。

---

## 2. 縦結合ラインのグラフィック仕様 (Vertical Connector Line)
各タイムラインアイテムの左側に、時系列の繋がりを視覚的に明示するための「縦結合ライン」を配置する。

* **デザイン仕様**:
  * 太さ: `2px` の実線（または破線）。
  * 色: `rgba(255, 255, 255, 0.08)`（グリッドボーダー等と整合した、静かで高級感のあるホワイト透過色）。
  * 結合: 最初のノードの直上から最終ノードの直下までシームレスに結合して流れるように配置。

---

## 3. プレミアム・グラスモーフィズムとの適合 (Glass UI Design Rules)
* **コンテナ背景**:
  * 他のダッシュボードカードと同様に `#1C1C1E`（Layer 2 固定色）および `1px solid rgba(255,255,255,0.1)` の枠線をベースとし、タイムラインリスト自体のコンテナは透過スクロール領域として設計。
  * スクロールバーは Apple ネイティブ風の極細・非表示に近い最小デザインを採用する。
* **テキスト配置**:
  * タイムスタンプとメッセージは、縦並びまたはグリッド整列させ、余白を重視したレイアウトにする。
