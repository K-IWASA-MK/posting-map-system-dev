# Isolation Profile (隔離プロファイル仕様書)

## 概要
`IsolationProfile` は、ファイルシステム、ネットワーク、IPC（プロセス間通信）などをどのように隔離するかを指定する定義体です。

## プロファイル構成例
1. **FULLY_ISOLATED**: ネットワーク完全無効、ファイルシステムは読み取り専用、IPCは親プロセスからのみ。
2. **NETWORK_DISABLED**: ネットワークのみ無効化し、一部書き込み可能なボリュームを許可。
3. **LIMITED_NETWORK**: 特定のドメイン/ポートへのTCP/UDP送信のみ許可。
4. **READ_ONLY**: ネットワークを許可するが、ファイルシステムは読み取り専用。
