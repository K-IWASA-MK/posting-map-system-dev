# Release Notes: v5.8.0 - Observability OS Foundation

**Release Date:** 2026-07-12
**Tag:** `v5.8.0`
**Milestone:** Sprint 8
**Status:** ✅ Completed / Approved

---

## 🎯 Overview (概要)
Sprint 8 では、AIOS の自律的な観測・分析基盤となる **Observability OS Foundation** を構築しました。Development OS とは完全に分離された独立サブシステムとして設計され、システムの状態、メトリクス、イベント履歴を厳格な SSOT（Single Source of Truth）原則に従い管理・統合します。

本リリースにより、次期 Sprint 9 で構築される **Learning Engine** が、一切の副作用を伴わずに安全かつ透過的に学習データを抽出できる「不変の参照基盤」が完成しました。

---

## 🚀 Key Features (主要な機能とアーキテクチャ)

### 1. CQRS Architecture (コマンド・クエリ責務分離)
状態の更新（Command）と参照（Query）を完全に分離するアーキテクチャを確立しました。
* **Projection Foundation:** イベント履歴から現行状態（Current State）を組み立てる参照専用モデル。
* **Metrics Foundation:** Raw Telemetry を消費し、一切の生データを改変することなく分析用集計データを提供する集計層。

### 2. SSOT Alignment (単一真実情報源の徹底)
* **Execution Ledger:** 履歴情報の唯一の真実（SSOT）。
* **Event Contract:** 履歴イベントの不変のスキーマ定義。
* **Projection:** 現行状態の SSOT。
* **Metrics:** 分析・集計結果の SSOT。
* **Telemetry:** Raw Measurements（観測生データ）の SSOT。

### 3. Facade & Read Models (安全な参照境界)
* **Live Monitor Foundation:** Projection と Metrics を統合し、AIOS の現在の稼働状況をリアルタイムに取得する Read-Only の Facade を構築しました。ビジネスロジックは一切持ちません。
* **Learning Source Foundation:** Ledger, Telemetry, Metrics を統合し、学習エンジン向けの不変なデータセット（`LearningDataset`）を抽出する Adapter 基盤を確立しました。

### 4. Observability OS Bootstrap (オーケストレーション)
* **ObservabilityOS:** 全ての Observability コンポーネントを統合するエントリポイント（Facade）。
* **Deterministic Sequencing:** 厳密な起動順序（EventBus -> Telemetry -> Projection -> Metrics -> LiveMonitor -> LearningSource）およびシャットダウン順序を保証。
