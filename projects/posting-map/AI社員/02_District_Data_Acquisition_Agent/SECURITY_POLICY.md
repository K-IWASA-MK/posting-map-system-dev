# SECURITY_POLICY.md - セキュリティ・ガードレール定義 (Security Policy & Guardrails)

## ■ 安全稼働原則 (Technical Guardrails)

### 1. 読込み専用データアクセス (Read-Only Source Connection)
- 照合データソース（全国住所データベース等）への書込みや改変は一切行わない。
- データの参照は読取り専用の接続またはローカルマスタファイルを介す。

### 2. 書込み制限 (Write Sandbox Limitation)
- 出力ファイルの書込みは、指定された `/storage/` ディレクトリ（またはテスト用の指定一時領域）の配下のみとする。
- システムのルート設定や、他のAI社員が管轄する `doGet` などの実行コードファイルを直接変更・書き換えることを厳格に禁止する。

### 3. No Calculation Policy (計算処理の排除)
- 自治体の境界や進捗・投票率の計算など、ビジネスドメインが担当すべき集計処理は本AI社員内には絶対に実装しない。
- 役割は「マスターからのデータ抽出とマッピング」のみに限定する。

### 4. ハッシュ保護 (Hash Protection)
- 出力する Raw データには、内容から算出した `sourceHash` を必ず付与し、後続の Validator がデータの欠落や改ざんをチェックできるように担保する。

### 5. 個人情報の不保持
- 配布員の個人情報、GPS追跡ログ、配布先の世帯情報などは一切取り扱わない。
- 対象はオープンな国勢データ、自治体境界メタデータ、および選挙区マスターのみとする。
