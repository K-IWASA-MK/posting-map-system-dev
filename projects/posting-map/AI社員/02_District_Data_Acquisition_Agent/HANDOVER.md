# HANDOVER.md - 業務引き継ぎ書 (Handoff Document)

## ■ 未着手タスク・宿題事項 (Outstanding Tasks)

1. **全国自治体コードソースの確定**
   - 静的な JSON ファイルとしてリポジトリに含めるか、実行時に動的APIから取得するかの設計判断。
   - 推奨方針：速度とネットワーク遮断耐性（オフライン優先）の観点から、ローカルの静的な市区町村マスターリゾルバーを用いる。

2. **部分的な区割り対応の境界定義**
   - 1つの自治体が複数の選挙区にまたがるケース（例: 「ふじみ野市」の一部が第8区、別の一部が他選挙区になるなど）への対応方法の設計。
   - 推奨方針：`DistrictResolver` 側で部分自治体（`partial: true`）フラグなどを制御可能にする。

---

## ■ 前提条件・他AI社員との依存関係 (Dependencies)

- **01_District_Initialization_Agent (全体初期化統制)**
  - データ取得完了通知を待ち受け、取得された `raw-district.json` の内容を `District Master` へアトミック登録する。

- **04_Area_Generation_Agent (エリア生成担当)**
  - `02_District_Data_Acquisition_Agent` が取得した自治体一覧およびコードを用いて、対象地区の住所分割（10件チャンク化）およびエリアファイル（areas.json）の初期モデルを構築する。
