# Code Intelligence Engine (CIE) Platform for VS Code

This extension integrates the CIE Platform commands directly into VS Code's Command Palette.

## Features

Run code intelligence tasks inside your workspace using the VS Code Command Palette:

- **CIE: Build** - Runs the sequential build orchestration pipeline.
- **CIE: Verify** - Verifies JSON artifacts integrity and syntax.
- **CIE: Doctor** - Diagnoses platform environment and details.
- **CIE: Report** - Generates and displays human-readable report.
- **CIE: Dashboard** - Displays coordinate location of Dashboard HTML.
- **CIE: API Status** - Verifies if the local CIE HTTP API Server is online.

All results are formatted and output to the dedicated output channel: `CIE Platform`.
